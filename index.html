About

Global GEOGLOWS forecast animation · select reaches · FLDPLN flood extent for the segments between them.

Model notes

FLDPLN is a steady-state, DEM-only screening model driven by synthetic rating curves; extents saturate at the library's maximum stage. Not for emergency use. Terrain: FABDEM (© DLR / Airbus, CC BY-NC-SA 4.0). Hydrography & forecast: GEOGLOWS.

Data

  • Streams hydrographs and FIM from the GEOGLOWS River Forecast System v2 and v3

Map layers

  • Basemaps from ArcGIS Living Atlas and USGS The National Map
  • RIVER-FLD global flood composite — near-real-time river flooding (CIMSS/SSEC, UW–Madison)
  • GOES / Himawari colorized IR — near-real-time satellite imagery (NOAA, via Esri)
  • VIIRS true color — daily corrected reflectance (NASA Earthdata, via Esri)

Open source software

  • MapLibre GL JS
  • Calcite UI Icons
  • Heroicons
  • Chart.js and plugins (date-fns adapter, matrix, zoom)
  • zarrita.js and numcodecs (Zarr access)
  • PMTiles
