Animación del pronóstico global GEOGLOWS · selecciona tramos · extensión de inundación FLDPLN para ellos.

Datos

  • Hidrogramas de ríos y mapas de inundación del GEOGLOWS River Forecast System v2 y v3
  • Terreno para el mapeo de inundaciones de FABDEM (© DLR / Airbus, CC BY-NC-SA 4.0)

Capas del mapa

  • Mapas base de ArcGIS Living Atlas y USGS The National Map
  • Compuesto global de inundaciones RIVER-FLD — inundación fluvial casi en tiempo real (CIMSS/SSEC, UW–Madison; VIIRS vía George Mason University)
  • IR coloreado GOES / Himawari — imágenes satelitales casi en tiempo real (NOAA, vía Esri Living Atlas)
  • Color natural VIIRS — reflectancia corregida diaria (NASA Earthdata / GIBS, vía Esri)

Software de código abierto

  • MapLibre GL JS
  • Calcite UI Icons
  • Heroicons
  • Chart.js y complementos (adaptador date-fns, matrix, zoom)
  • zarrita.js y numcodecs (acceso a Zarr)
  • PMTiles
