Global GEOGLOWS forecast animation · select reaches · FLDPLN flood extent for them.

Data

  • Streams hydrographs and flood maps from the GEOGLOWS River Forecast System v2 and v3
  • Flood mapping terrain from FABDEM (© DLR / Airbus, CC BY-NC-SA 4.0)

Map layers

  • Basemaps from ArcGIS Living Atlas and USGS The National Map
  • RIVER-FLD global flood composite — near-real-time river flooding (CIMSS/SSEC, UW–Madison; VIIRS via George Mason University)
  • GOES / Himawari colorized IR — near-real-time satellite imagery (NOAA, via Esri Living Atlas)
  • VIIRS true color — daily corrected reflectance (NASA Earthdata / GIBS, via Esri)

Open source software

  • MapLibre GL JS
  • Calcite UI Icons
  • Heroicons
  • Chart.js and plugins (date-fns adapter, matrix, zoom)
  • zarrita.js and numcodecs (Zarr access)
  • PMTiles
